1. ภาพรวมและการเข้าใช้งาน

ระบบบริหารจัดการกีฬาสี 2569 ใช้สำหรับ ลงทะเบียนทีม อนุมัติทีม บันทึกผลการแข่งขัน และติดตามคะแนนกีฬาสี ของโรงเรียนผดุงราษฎร์ เข้าใช้งานได้ที่
https://prs-sportday.teachertan.workers.dev

1.1 บทบาทผู้ใช้งาน

บทบาทชื่อในระบบสิทธิ์หลัก
Adminadminเข้าถึงทุกส่วน จัดการ user ทั้งหมด
ครูกีฬาสีteacherเหมือน Admin แต่จัดการ user ไม่ได้
ครูประจำสีhouse_teacherอนุมัติทีมสีตัวเอง ลงทะเบียนทีมได้
ผู้ตัดสินrefereeบันทึกผลเฉพาะกีฬาที่รับผิดชอบ
การกำหนด role อัตโนมัติ: เมื่อ login ครั้งแรก ระบบจะกำหนด role ให้อัตโนมัติ — ครูที่มีห้องประจำชั้นจะได้ ครูประจำสี ตามสีห้องนั้น ครูที่ไม่มีห้องประจำชั้นจะได้ ผู้ตัดสิน Admin สามารถเปลี่ยน role ได้ที่เมนู ผู้ดูแลระบบ → จัดการผู้ใช้

1.2 การ Login เข้าระบบ

Login ด้วยบัญชีระบบเช็คชื่อ

ระบบกีฬาสีเชื่อมต่อกับระบบเช็คชื่อโรงเรียน — ใช้ username / password เดิม จากระบบเช็คชื่อได้เลย ไม่ต้องสมัครใหม่

  1. เปิดเบราว์เซอร์ไปที่ prs-sportday.teachertan.workers.dev
  2. กรอก Username และ Password ของระบบเช็คชื่อ
  3. กดปุ่ม "เข้าสู่ระบบ"
  4. ระบบพาไปยังหน้า Dashboard อัตโนมัติ
หากเข้าไม่ได้: ตรวจสอบว่า username/password ของระบบเช็คชื่อถูกต้อง และบัญชีนั้นเปิดใช้งานอยู่
2. ผู้ดูแลระบบ (Admin / ครูกีฬาสี)

Admin ครูกีฬาสี

2.1 จัดการผู้ใช้งาน

คลิก "ผู้ดูแลระบบ" ในเมนู → กดปุ่ม "จัดการ →" ในส่วนจัดการผู้ใช้

  1. รายชื่อครูที่เคย login ผ่าน SSO จะปรากฏที่นี่
  2. คลิก "แก้ไข" ข้างชื่อที่ต้องการ
  3. เลือก บทบาท (teacher / house_teacher / referee / ...)
  4. หากเป็น house_teacher — เลือก สีบ้าน ให้ถูกต้อง
  5. หากเป็น referee — เลือก กีฬาที่รับผิดชอบ
  6. กด "บันทึก"
ครูที่ยังไม่ได้ login จะยังไม่ปรากฏในรายการ — ต้องให้ครู login อย่างน้อย 1 ครั้งก่อน

2.2 เปิด-ปิดช่วงลงทะเบียน & ซิงค์นักเรียน

เปิด-ปิดช่วงลงทะเบียน

  • ในหน้า Admin เลื่อนลงหาส่วน "ช่วงเวลาลงทะเบียน"
  • กดปุ่ม "เปิดลงทะเบียน" พร้อมกำหนดวันเริ่ม-วันสิ้นสุด
  • ปิดโดยกด "ปิดลงทะเบียน"

ซิงค์รายชื่อนักเรียน

  • ดึงข้อมูลนักเรียน (ชื่อ, ห้อง, QR Code) จากระบบเช็คชื่อ
  • กดปุ่ม "ซิงค์ข้อมูลนักเรียน" รอจนขึ้น "ซิงค์สำเร็จ" (10–30 วินาที)
  • ควรซิงค์ใหม่ทุกครั้งที่มีการแก้ไขข้อมูลนักเรียนในระบบเช็คชื่อ

2.3 ตั้งค่า Bracket & จัดการตารางแข่ง

ตั้งค่า Bracket (สายการแข่งขัน)

  • คลิก "จัดการ Bracket →" → เลือกชนิดกีฬา
  • สำหรับแต่ละแมตช์ เลือก "แมตช์ถัดไป" และ "ช่อง A/B" ที่ผู้ชนะจะไป
  • กด "บันทึก" — ระบบจะเลื่อนทีมชนะให้อัตโนมัติหลังบันทึกผล

แก้ไขตารางแข่ง

  • คลิก "ตารางแข่ง / ผลการแข่ง" → กด "✏ แก้ไขตาราง" ในแมตช์ที่ต้องการ
  • แก้ไข วันที่ / สนาม / เลขที่แมตช์ / หมายเหตุ แล้วกด "บันทึก"
3. ครูประจำสี (House Teacher)

ครูประจำสี

ครูประจำสีมีหน้าที่หลักคือ ดูแลการลงทะเบียนทีมและอนุมัติทีมในสีของตัวเอง

3.1 อนุมัติทีม

  1. คลิก "ผู้ดูแลระบบ" ในเมนู
  2. เลื่อนดูรายการทีมที่สถานะ "รออนุมัติ"
  3. คลิก "ดูรายชื่อ" เพื่อตรวจสอบรายชื่อนักเรียนในทีม
  4. กด "อนุมัติ" หากถูกต้อง หรือ "ตีกลับ" พร้อมระบุเหตุผล
ครูประจำสีจะเห็นเฉพาะทีมในสีของตัวเองเท่านั้น

3.2 ลงทะเบียนทีม

  1. คลิก "ทีม / การลงทะเบียน" → เลื่อนลงหาส่วน "ลงทะเบียนทีมใหม่"
  2. เลือก ชนิดกีฬา ที่ต้องการ
  3. สแกน QR Card นักเรียนหรือค้นหาชื่อเพื่อเพิ่มสมาชิก
  4. กรอก ชื่อทีม (ถ้ามี) แล้วกด "ส่งลงทะเบียน"

สถานะทีม

  • ฉบับร่าง — บันทึกไว้ยังไม่ส่ง
  • รออนุมัติ — ส่งแล้ว รอครูประจำสีตรวจ
  • อนุมัติแล้ว — พร้อมเข้าแข่งขัน
  • ถูกตีกลับ — ต้องแก้ไขแล้วส่งใหม่
4. ผู้ตัดสิน (Referee)

ผู้ตัดสิน

ผู้ตัดสินมีหน้าที่ บันทึกผลการแข่งขันและจัดการการรายงานตัวของทีม เฉพาะกีฬาที่รับผิดชอบ

4.1 ตั้งค่ากีฬาที่รับผิดชอบ

  1. คลิก "กีฬาของฉัน" ในเมนูด้านบน
  2. เลือก checkbox กีฬาที่ตัวเองเป็นผู้ตัดสิน (เลือกได้หลายรายการ)
  3. กด "บันทึก"
Admin สามารถกำหนดกีฬาให้ผู้ตัดสินได้จาก Admin → จัดการผู้ใช้ ด้วยเช่นกัน

4.2 บันทึกผลการแข่งขัน

  1. คลิก "ตารางแข่ง / ผลการแข่ง" — จะเห็นเฉพาะกีฬาที่รับผิดชอบ
  2. กดปุ่ม "รายงานตัว / บันทึกผล" ในแมตช์ที่ต้องการ
  3. รายงานตัว: กดปุ่ม ✓ ข้างชื่อทีมเพื่อยืนยันว่าทีมมาแล้ว
  4. เปลี่ยนสถานะเป็น "กำลังแข่ง" เมื่อเริ่มแมตช์
  5. กรอก คะแนนทีม A และ คะแนนทีม B
  6. เปลี่ยนสถานะเป็น "จบแล้ว" แล้วกด "บันทึก"

Walkover (ทีมไม่มาแข่ง)

หากทีมใดทีมหนึ่งไม่มารายงานตัว กดปุ่ม "Walkover" ให้อีกทีมชนะโดยปริยาย ระบบตั้งคะแนนเป็น 3-0 อัตโนมัติ

4.3 QR Scanner รายงานตัว

  1. ในหน้าบันทึกผล กดปุ่ม "สแกน QR รายงานตัว"
  2. หน้า Scanner จะเปิดขึ้น — ยิงกล้องไปที่ QR Card นักเรียน
  3. ระบบตรวจสอบและบันทึกการรายงานตัวให้อัตโนมัติ
  4. กด "ย้อนกลับ" เมื่อเสร็จสิ้น
ต้องเข้าผ่านเบราว์เซอร์บนมือถือและอนุญาตให้ใช้กล้องเพื่อสแกน QR ได้
5. หน้าสาธารณะ (ดูได้ทุก role)

ทุก role

ตารางแข่ง / ผลการแข่ง

การกรองข้อมูล

  • 📅 วันที่ — กรองเฉพาะวันที่เลือก
  • 🏅 ชนิดกีฬา — กรองเฉพาะกีฬาที่เลือก
  • 🔄 รอบ — รอบคัดเลือก / รอบชิง
  • 📋 สถานะ — รอแข่ง / กำลังแข่ง / จบแล้ว

สรุปผลรายวัน

คลิก "สรุปผลรายวัน" ในเมนู — แสดงผลการแข่งขันทั้งหมดของวันนั้น จัดกลุ่มตามชนิดกีฬา พร้อม Scoreboard คะแนนรวมแต่ละสี

หน้า Dashboard

หน้าแรกหลัง login แสดงภาพรวม: คะแนนรวมของแต่ละบ้านสี จำนวนแมตช์วันนี้ และทีมที่ได้รับการอนุมัติแล้ว
